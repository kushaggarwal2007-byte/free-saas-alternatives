## 🐳 Quickstart One-Liner Deployments

### 1. Launch Coolify (Self-Hosted Free Cloud PaaS):
```bash
curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash
```

### 2. Launch n8n (Free Zapier Alternative):
```bash
docker run -it --rm --name n8n -p 5678:5678 -v ~/.n8n:/home/node/.n8n docker.n8n.io/n8nio/n8n
```

### 3. Launch Uptime Kuma (Free Uptime Monitoring):
```bash
docker run -d --restart=always -p 3001:3001 -v uptime-kuma:/app/data --name uptime-kuma louislam/uptime-kuma:1
```

### 4. Launch Stirling-PDF (Free Adobe Acrobat Alternative):
```bash
docker run -d -p 8080:8080 -v ./trainingData:/usr/share/tessdata --name stirling-pdf frooodle/s-pdf:latest
```
